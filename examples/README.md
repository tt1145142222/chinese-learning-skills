# 示例输入

这些文件为本次导出新编或虚构的输入，没有真实学生数据、课件正文或论文附件。可把 examples 中的单个目录复制到自己的项目，再在助手对话中调用对应 Skill。

- `math-practice/topics.md`：两个简单原创数学习题与范围说明。
- `math-practice/reference-answers.md`：对应验算结果，单独保存，学生练习稿不应含答案。
- `lesson-cycle/course-brief.md`：虚构课程与匿名学习者，用于建立课程档案。
- `caikeji/exam-scope.md`：仅包含自拟题型和范围，实际课程材料由使用者自行提供。
- `maogai/request.md`：仅示范如何表达章节范围与交付要求，未包含课程内容。

使用这些提示并不等于完整流程已经测试通过；最终生成的文档仍需数学/内容复核和版面检查。
