\section*{一、基础与方法识别}

\begin{problem}{预测题}{\ImportanceHigh}{10}
设函数 \(f(x)=x^3-3x\)。求 \(f(x)\) 在区间 \([-2,2]\) 上的最大值与最小值。
\AnswerSpace[35mm]
\Solution
{最大值为 \(2\)，最小值为 \(-2\)。}
{导数、单调性、闭区间最值。}
{先求驻点，再比较端点与驻点函数值。}
{
\[
f'(x)=3x^2-3=3(x-1)(x+1),
\]
故驻点为 \(x=-1,1\)。比较
\[
f(-2)=-2,\quad f(-1)=2,\quad f(1)=-2,\quad f(2)=2.
\]
因此最大值为 \(2\)，最小值为 \(-2\)。
}
{
\begin{enumerate}
  \item 正确求导并求出驻点，3 分。
  \item 比较端点与驻点函数值，5 分。
  \item 写出最大值与最小值，2 分。
  \item 易错点：只检查驻点，遗漏闭区间端点。
\end{enumerate}
}
\end{problem}
