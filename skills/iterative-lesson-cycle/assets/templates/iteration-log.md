# Iteration Log

> Copy this file into a course project. Add one complete session block for each teaching cycle; preserve prior evidence and distinguish the plan from what actually happened.

## Session index

Allowed `Session phase` values are exactly `planned`, `in progress`, `awaiting practice`, `awaiting correction`, and `cycle complete`.

| Session | Date | Topic | Session phase | Phase note | Linked artifacts |
| --- | --- | --- | --- | --- | --- |
|  |  |  | planned |  |  |

Enter exactly one allowed value in `Session phase`; never add qualifiers, punctuation, or combined text to that cell. Put details such as active carry-forward, a deadline checkpoint, or a deferred schedule in `Phase note`. A deferral never changes the phase or substitutes for evidence. Keep session phase `awaiting correction` when required correction/retest evidence is missing, or when submitted evidence is insufficient to complete the prescribed action. Use `cycle complete` only after the required evidence has been submitted and reviewed, the prescribed correction/retest action is complete, and learner-model and iteration-log updates are written. Issuing, rescheduling, or deferring a correction or retest does not complete the cycle.
